ACADIA ONE is a course selection tool for Acadia University, built to streamline the way students explore, filter, and schedule their courses. The entire app is designed around user experience: instant page transitions via prefetching, no layout shift, and all UI state synced in the URL so links are shareable and the back button always works.

## Stack

- **Frontend**: React 19, TanStack Router (file-based), TanStack React Query, Tailwind CSS v4, shadcn/ui
- **Backend**: Convex (serverless functions, real-time database)
- **Build**: Vite, Bun
- **Deployment**: Vercel

## Core Patterns

### Prefetching with `ensureQueryData`

Route loaders in `src/routes/explore.tsx` call `context.queryClient.ensureQueryData()` with `convexQuery()` to fetch all required data before the route renders. Components then read that data via `useSuspenseQuery`, which means no loading spinners and no layout shift -- the data is already in cache when the component mounts.

### URL State as Source of Truth

All filter and view state (department, term, professor, schedule view, pagination) lives in URL search params, validated with Zod via `zodValidator`. Hooks like `src/hooks/use-explore-filters.ts` read state through `routeApi.useSearch()` with selectors and write through `useNavigate()` with search updater functions. Default values are stripped from the URL via `stripSearchParams` to keep URLs clean.

### React Compiler

The React Compiler is enabled via `babel-plugin-react-compiler` in `vite.config.ts`. Because the compiler automatically memoizes components and hooks, you generally do **not** need manual `useMemo`, `useCallback`, or `React.memo`. Only add them in cases where the compiler genuinely misses an optimization.

## Scraping Pipelines (`convex/workflow/`)

These are Convex actions that populate and maintain the database. They use `ctx.scheduler.runAfter()` to chain work with delays to avoid rate limits.

| File                | Purpose                                                        |
| ------------------- | -------------------------------------------------------------- |
| `populate.ts`       | Seeds departments, courses, and professors from Acadia         |
| `processCourse.ts`  | Pulls detailed section data for each course                    |
| `pullReviews.ts`    | Fetches Rate My Professor ratings for professors               |
| `rmpLink.ts`        | AI-powered matching of professors to RMP profiles (via Gemini) |
| `pullUserData.ts`   | Pulls authenticated student data (grades, programs, evals)     |
| `syncAggregates.ts` | Recomputes aggregate stats for courses and professors          |
